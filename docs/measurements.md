# Замеры цветов 1С (веха M3a)

Дата: 2026-11-22. Задание: `docs/tasks/m3a-measure.md`.

## Условия

- Платформа: 8.3.27.1989, конфигуратор x64, тестовая база `D:\tmp\Платформа\1` («Каркасная конфигурация»).
- Экран: 2560×1440, 96 dpi, масштаб 100 %.
- Пиксели сняты через `PrintWindow(PW_RENDERFULLCONTENT)` по окнам `1cv8.exe` (чужие окна поверх не мешают), чтение — `LockBits`. Мерились сплошные заливки вдали от краёв.
- Проверка искажений: фон дерева, палитры и редактора даёт ровно `#FFFFFF`; ядра глифов текста совпадают с RGB из «Параметров» без отклонений (`#FF0000`, `#0000FF`, `#008000`, `#963200`, `#000000`). Искажений нет.

## Как получены значения 1С по умолчанию

Цвета редактора хранятся в `%APPDATA%\1C\1cv8\1cv8.pfl`, блок `ModuleColorCategory`, формат `{3,0,{BGR}}`; `{3,4,{0}}` — «Авто».

- Shift+F4 в поле цвета ставит «Авто». Это **не** значение по умолчанию: всё рисуется чёрным по белому.
- Настоящие умолчания получены так: конфигуратор закрыт, блок `ModuleColorCategory` удалён из `1cv8.pfl`, конфигуратор запущен заново. Значения ниже прочитаны в «Параметрах» и проверены пикселями.
- Схема владельца возвращена копированием исходного `1cv8.pfl` (снят до замера). Хеш восстановленного файла совпал с копией.

## Схема владельца, найденная до замера

Совпадает с `docs/requirements.md`, кроме одного: константы «Число», «Строка», «Дата» и «Идентификаторы» были `0,0,0` (`#000000`), а не `#F8F8E8`. Фон `255,255,255`. Шрифт Fira Code Retina 11.

## Совпадения цветов по умолчанию (перекраска по цвету их не разведёт)

| Цвет 1С | Категории | Цели владельца |
|---|---|---|
| `#FF0000` | ключевые слова, операторы | `#DC8500` / `#C82626` — **конфликт** |
| `#000000` | число, строка, дата, прочее | все `#F8F8E8` — конфликта нет |
| `#FFFFFF` | фон, текущий и выбранный идентификатор (стиль) | `#202028` / `#8465C5` / `#B4B4B4` — **конфликт**: подсветки по умолчанию не видно, при перекраске только по цвету она останется невидимой |
| `#000000` | текст и выделение-инверсия | выделение рисуется инверсией, а не заливкой |

Комментарии (`#008000`) и препроцессор (`#963200`) различаются. Фоны поиска (`#F3EECD`), подсказки (`#FFFAD9`) и границ блока (`#E6E6E6`) различаются. Но `#FFFAD9` совпадает со стилем «Фон подсказки», а `#F3EECD` близок к фонам панелей (`#F5F2DD`).

## Проверка восстановления

- Конфигуратор запущен повторно. В «Параметрах» видны значения владельца: ключевые слова 220,133,0; комментарии 69,133,184; фон 255,255,255; поиск 160,30,100; подсказка 82,82,120. Диалог закрыт кнопкой «Отмена».
- После выхода `ModuleColorCategory` в `1cv8.pfl` содержит те же значения, что и до замера.

## Следы в тестовой базе

- В конфигурации сохранён общий модуль `ОбщийМодуль1` с примером кода.
- Справочник `Справочник1` и его форма созданы во втором заходе. При выходе ответ «Нет», в конфигурацию не сохранены.
