# Задание: веха M3a — цвета 1С с экрана

Контекст: тёмная тема конфигуратора 1С переписывается с нуля под MIT (этот репозиторий). Требования — `docs/requirements.md`, архитектура — `docs/architecture.md`. Тема перекрашивает цвета при отрисовке, настройки 1С не трогает; ключи `from` карт `themes/default/palette.json` снимаются этим замером. Код и данные прежней реализации (`D:\projects\darktheme\src`, `tools`, `build`) не читать.

## Шаги

1. Загрузить навык computer use, запросить доступ к `1cv8.exe`.
2. Запустить конфигуратор x64 8.3.27 на тестовой базе (её можно ломать; рабочие базы не трогать):
   `"C:\Program Files\1cv8\8.3.27.1989\bin\1cv8.exe" DESIGNER /F"D:\tmp\Платформа\1"`
3. «Сервис → Параметры → Модули → Редактирование»: записать текущие значения (ожидается схема владельца из `docs/requirements.md` с белым фоном), затем сбросить цвета на значения 1С по умолчанию. Настройки общие для пользователя Windows — владелец разрешил.
4. Создать в тестовой базе общий модуль с примером кода: ключевые слова, числа, строки, даты, идентификаторы, операторы, комментарии, препроцессор (`#Если`); вызвать подсветку текущего/выбранного идентификатора, границы блока, результат поиска, контекстную подсказку.
5. Снять цвета:
   - редактор: фон и каждая категория текста (значения брать из «Параметров» — точнее сглаженных пикселей);
   - дерево конфигурации, палитра свойств;
   - главное и контекстное меню: фон, текст, выделение;
   - панели команд и рамки;
   - справка F1: фон, шапка статьи, ссылки, посещённые ссылки; синтакс-помощник;
   - типовой диалог и форма элемента справочника.

   Пиксели — скриптом PowerShell (`System.Drawing`, `CopyFromScreen`, `GetPixel`) на непрерывных заливках вдали от краёв; сглаженный текст и края не мерить. Проверить искажения по известному `#FFFFFF`, записать масштаб экрана.
6. Вернуть в «Параметрах» схему владельца ровно как была и проверить, что она сохранилась. Закрыть конфигуратор тестовой базы.
7. Записать результат числами в `docs/measurements.md`:
   - таблица «элемент → контекст (editor/panel/popup/help/dialog) → цвет по умолчанию → откуда снят (настройки/пиксель)»;
   - масштаб экрана, версия платформы;
   - совпадения цветов по умолчанию у категорий, которым владелец назначил разные цвета (ключевые слова/операторы, комментарии/препроцессор, фоны поиска/подсказки/выделения).

## Запреты

- Никаких inject/unload и загрузки DLL.
- Снимки экрана — только во временной папке сессии, не в репозиторий: на них может быть код конфигурации.
- Не коммитить.
- Не трогать файлы, которые параллельно пишет разработчик: `core/`, `patch/`, `theme/`, `probe/`, `loader/`, `tests/`, `build.cmd`, `themes/`. Писать только `docs/measurements.md`.

Готово, когда `docs/measurements.md` заполнен и схема владельца восстановлена.
