# 1c-configurator-dark

Тёмная тема для конфигуратора 1С:Предприятие (x86 и x64). DLL перекрашивает интерфейс внутри уже запущенного `1cv8.exe`, файлы платформы не меняются.

**Статус:** проект пишется с нуля, рабочей сборки пока нет.

## Принципы

- Только конфигуратор: образ `1cv8.exe` с видимым окном «Конфигуратор». Тема загружается после полной загрузки окна, не при старте процесса.
- Цвет меняется до отрисовки. Пиксели кэшированных поверхностей не переписываются, поверх готового кадра ничего не дорисовывается.
- Без автозагрузки, IFEO и системных каталогов. Выгрузка возвращает исходный вид.
